# 外贸获客Agent Skill

## 概述
外贸获客Agent是一个全自动的外贸客户开发系统，通过自然语言指令驱动，自动完成客户搜索、官网爬取、联系方式提取、客户评分、CRM录入、开发信生成与邮件发送的完整闭环。

## 核心能力

### 1. 自然语言指令解析
- 理解用户的业务需求（如"帮我开发5个医疗客户"）
- 提取关键信息：行业、客户数量、地区等
- 判断任务类型并路由到对应工作流

### 2. 任务路由与编排
根据用户指令自动选择并编排以下MCP插件：
- **CRM插件**：管理客户数据
- **搜索插件**：搜索潜在客户
- **爬取插件**：提取网站联系信息
- **评分插件**：评估客户质量
- **邮件插件**：生成并发送开发信

## 工作流程

### 完整获客流程
```
用户指令 → 意图解析 → 客户搜索 → 官网爬取 → 联系方式提取 → 客户评分 → CRM录入 → 开发信生成 → 邮件发送 → 结果汇报
```

### 流程说明

#### 步骤1：意图解析
- 输入：自然语言指令（如"帮我开发5个医疗客户"）
- 输出：结构化任务参数（行业、数量、地区等）

#### 步骤2：客户搜索
- 使用搜索插件搜索目标行业的潜在客户
- 支持搜索引擎、LinkedIn、B2B平台等多渠道搜索

#### 步骤3：官网爬取
- 对搜索结果中的公司官网进行爬取
- 获取网站标题、描述、内容等信息

#### 步骤4：联系方式提取
- 从网站内容中提取邮箱地址、电话号码、联系人姓名
- 提取社交媒体链接

#### 步骤5：客户评分
- 根据网站质量、联系方式完整性、行业匹配度等维度评分
- 生成客户等级（A/B/C/D）和开发建议

#### 步骤6：CRM录入
- 将客户信息录入飞书多维表格
- 更新客户状态和评分

#### 步骤7：开发信生成
- 根据客户等级和行业生成个性化开发信
- 支持多种模板类型

#### 步骤8：邮件发送
- 批量发送开发信
- 记录发送结果

#### 步骤9：结果汇报
- 汇总整个获客流程的结果
- 生成详细报告

## 支持的任务类型

### 1. 完整获客任务
- **指令示例**："帮我开发5个医疗客户"
- **执行流程**：完整执行上述9个步骤

### 2. 客户搜索任务
- **指令示例**："搜索医疗器械行业的潜在客户"
- **执行流程**：步骤1-2

### 3. 客户信息完善任务
- **指令示例**："完善这些客户的联系方式"
- **执行流程**：步骤3-4

### 4. 客户评分任务
- **指令示例**："评估这些客户的质量"
- **执行流程**：步骤5

### 5. 开发信发送任务
- **指令示例**："给这些客户发送开发信"
- **执行流程**：步骤7-8

### 6. CRM管理任务
- **指令示例**："查看所有待开发客户"
- **执行流程**：仅CRM操作

## 输入输出规范

### 输入参数
| 参数 | 类型 | 描述 | 必填 |
|------|------|------|------|
| instruction | string | 用户的自然语言指令 | 是 |
| industry | string | 目标行业 | 否 |
| count | int | 客户数量 | 否 |
| region | string | 目标地区 | 否 |
| customer_ids | list | 已有的客户ID列表 | 否 |

## 配置要求

### 环境变量
- FEISHU_APP_ID: 飞书应用ID
- FEISHU_APP_SECRET: 飞书应用密钥
- FEISHU_BASE_TOKEN: 飞书多维表格Token
- SEARCH_SERP_API_KEY: SerpAPI密钥（可选）
- EMAIL_SMTP_SERVER: 邮件SMTP服务器
- EMAIL_SMTP_USERNAME: 邮件用户名
- EMAIL_SMTP_PASSWORD: 邮件密码

## 使用示例

### 示例1：完整获客
```
指令：帮我开发5个医疗设备客户

执行结果：
- 搜索到10个潜在客户
- 爬取了5个官网
- 提取到8个邮箱地址
- 评分结果：A类客户2个，B类客户3个
- 成功录入CRM
- 发送5封开发信
```

### 示例2：批量评分
```
指令：评估这些客户的质量
客户列表：[客户A, 客户B, 客户C]

执行结果：
- 客户A: 评分85，A级
- 客户B: 评分65，B级
- 客户C: 评分45，C级
```

### 示例3：发送开发信
```
指令：给A级客户发送个性化开发信

执行结果：
- 生成2封个性化开发信
- 成功发送2封邮件
```

## 扩展能力

### 新增任务类型
通过修改意图解析逻辑，可以支持更多任务类型：
- 竞争对手分析
- 市场调研
- 客户跟进提醒

### 新增数据源
通过扩展搜索插件，可以支持更多数据源：
- 行业展会数据库
- 海关数据
- 社交媒体数据

### 新增评分维度
通过扩展评分插件，可以增加更多评分维度：
- 公司规模
- 市场份额
- 财务状况
- 技术实力

## 注意事项

1. **遵守法律法规**：爬取网站时需遵守robots.txt规则和相关法律法规
2. **数据隐私保护**：妥善处理客户隐私信息
3. **邮件发送频率**：避免发送垃圾邮件，遵守邮件发送频率限制
4. **API调用限制**：注意各第三方API的调用频率限制
5. **错误处理**：各步骤都有完善的错误处理和重试机制
